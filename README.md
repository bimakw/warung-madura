# Warung Madura

[![MIT License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

E-commerce web app for a traditional Indonesian warung, built with Next.js 16, TypeScript, and Tailwind CSS 4.

**Demo:** [warung-madura-benno.netlify.app](https://warung-madura-benno.netlify.app)

## Running

```bash
npm install
npm run dev
```

Or via Docker:

```bash
docker compose up -d
```

## Features

- Product catalog with search/filter by category
- Shopping cart with persistent localStorage
- Checkout via WhatsApp
- Dark mode, wishlist, PWA-ready

## Testing

```bash
npm run test:run
```
